# Sistema de Notas

Projeto desenvolvido para praticar JavaScript e lógica de programação.

## Funcionalidades

- Cadastro de alunos e notas
- Cálculo da média da turma
- Maior e menor nota
- Alunos acima e abaixo da média
- Quantidade de aprovados e reprovados
- Distribuição das notas por faixa
